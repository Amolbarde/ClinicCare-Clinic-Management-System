# ClinicCare – Clinic Management System

A Java Swing and PostgreSQL-based desktop application designed to simplify clinic operations and manage patient records, doctors, and appointments.

## Project Overview

ClinicCare is a desktop-based Clinic Management System developed using Java Swing and PostgreSQL. It provides a graphical interface for managing clinic information and database records.

## Technologies Used

- Java
- Java Swing
- JDBC
- PostgreSQL
- Eclipse IDE

## Features

- Admin Login
- Doctor Management
- Patient Management
- Appointment Booking
- Appointment Records
- PostgreSQL Database Integration
- Graphical User Interface

## Database Setup

1. Install PostgreSQL.
2. Create a database named `clinic`.
3. Open the `database/clinic.sql` file.
4. Execute the SQL commands in PostgreSQL.
5. Configure your database connection in the application.

## Run the Project

1. Clone this repository.
2. Import the project into Eclipse IDE.
3. Add the PostgreSQL JDBC driver.
4. Configure the database connection.
5. Run `ClinicManagementSystem.java`.

## Database Configuration

Update your local database configuration before running the application.

Do not upload database passwords or other private credentials to GitHub.
